# Security policy

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting](../../security/advisories/new)
for a suspected security issue. Do not include passwords, access tokens, private game files, or extracted
assets in a report. If private reporting is unavailable, open a public issue with only a high-level
description and ask for a private contact route; do not publish exploit details before coordination.

This is an experimental local conversion toolchain, not a security product. Reports are handled by the
repository maintainer on a best-effort basis; no response-time or supported-version guarantee is offered.

## Supported versions

Security fixes target the current `main` branch. Older commits and experimental builds are not maintained.
