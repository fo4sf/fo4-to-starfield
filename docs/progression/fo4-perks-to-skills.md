### 2. Engineering Opinion: Perk Cadence, Skill Points & the Two Character Modes

The owner's `21 Nov` continuity rule establishes **two player-selected campaign options** — **(Mode 1) Complete Reset per Game** (fresh character per title, unlocking free multi-world access once the games are finished) and **(Mode 2) Carried Character** (retaining S.P.E.C.I.A.L., skills, and perks from game to game, standard for Survival). Evaluating progression numbers against **both** modes exposes a key tension in the `21 Nov` draft: **a single static rate calibrated for a 6-game Level-`178` run starves a 1-game Complete-Reset run, while a 1-game rate floods a 6-game Carried-Character run.**

1. **Perk Cadence (`1` per level vs `FO4SF_PerkCadenceLevels`):**
   - **Why per-title border switching (`FO3=1, FNV=2, FO1/2=3`) should be retired:** We **agree** with the `21 Nov` note that changing perk cadence when one character walks from the Capital Wasteland into the Mojave feels arbitrary, and FO1/FO2's classic `1`-per-`3` cadence was balanced for campaigns ending at Level `12–21`, not Level `72` on FO4's XP curve.
   - **Where we disagree with unconditional `1` perk per level for Carried Characters:** After folding `61` (`62`) skill-like FO4 ranks into the `13` skills, FO4 contributes `168` (`181`) perk ranks, FO3 `93`, and FNV `175` — but **over `35` core perks overlap across those games** (*Toughness*, *Refractor*, *Life Giver*, *Action Boy*, *Better Criticals*, *Bloody Mess*, *Grim Reaper's Sprint*, *Four Leaf Clover*, *Mysterious Stranger*, *Miss Fortune/Ricochet*, *Sniper*, *Concentrated Fire*, *Penetrator*, *Commando*, *Gunslinger*, *Iron Fist/Paralyzing Palm*, *Big Leagues/Slayer/Super Slam*, *Demolition/Splash Damage*, *Sneak/Silent Running/Light Step*, *Mister Sandman*, *Ninja*, *Cannibal*, *Lead Belly*, *Rad Resistance*, *Chem Resistant*, *Adamantium Skeleton*, *Solar Powered*, *Night Person*, *Nerd Rage!*, *Lady Killer/Black Widow*, *Animal Friend*, *Robotics Expert*, *Educated*, *Comprehension*, *Strong Back*, *Fortune Finder*, *Scrounger*). Once duplicates are merged into one shared table (`~250–290` unique non-mutually-exclusive ranks), **`177` perk picks at Level `178` buys `60%–70%` of the entire franchise catalog**, erasing build specialization by Game 4.
   - **Recommended Solution (keyed to Campaign Mode via existing `GLOB FO4SF_PerkCadenceLevels`, zero border switching):**
     - **Complete-Reset Mode (`1` game, ~Level `50–72`):** Set `FO4SF_PerkCadenceLevels = 1` (`1` perk/level -> `49–71` perks in that standalone campaign, matching FO4/FO3 pacing while leaving `~65–75%` of perks unpicked).
     - **Carried-Character Mode (`2–6` games, ~Level `100–178`):** Use a **stepped level-bracket cadence** (still driven by `FO4SF_PerkCadenceLevels` updated at milestone levels, never by title border): **`1` perk/level at Levels `2–30`** (`29` perks — preserves fast, rewarding early levelling in Game 1), **`1` per `2` levels at Levels `31–80`** (`+25` = `54` perks by end of Game 1), and **`1` per `3` levels at Level `81+`** (`+33` = **`87` perks at Level `178`**, ~`30–35%` of the deduplicated multi-title catalog, matching New Vegas's build-defining scarcity across all 6 games). If a single flat integer is preferred over brackets, `FO4SF_PerkCadenceLevels = 2` (`89` perks at L178) is far healthier for Carried-Character longevity than `1`.

2. **Skill Points (`10 + floor(INT/2)` vs `5 + floor(INT/2)`) & Stepped Mastery Cost:**
   - With `Pool = 40` (`INT = 5`, `LCK = 5`), `1` Background (`+10` × 3), and `3` Tag Skills (`+15` × 3), `compute_initial_skills` in `src/fo4sf/progression/tables.py` starts a character at **`~282 / 1,300` total skill points** (`1,018` points below all-`100`).
   - At `10 + floor(INT/2)` (`12` pts/lvl at `INT = 5`), `0` skill books maxes all `13` skills at **Level `86`** — and with even `200` points from books/bobbleheads, all `13` skills hit `100` by **Level `69` (inside Game 1)**.
   - However, flatly halving to `5 + floor(INT/2)` (`7` pts/lvl) punishes **Complete-Reset** players who finish a tighter main quest around Level `35–45`.
   - **Recommended Solution (Classic Fallout Stepped Skill Cost — works in BOTH modes):** Keep base points generous (`10 + floor(INT/2)` in Complete-Reset; `8 + floor(INT/2)` or `5 + floor(INT/2)` in Carried-Character) **and adopt Fallout 1/2's stepped allocation cost above `75`**: `1` skill point per `+1` up to `75`, and **`2` skill points per `+1` from `76` to `100`** (`+325` extra points required across `13` skills to reach `100`). A Game-1 character still reaches `50–75` competence rapidly (Advanced/Expert locks, Tier 2–3 crafting), while true `100` mastery becomes a deliberate investment that stretches naturally past Level `125+` in Carried-Character runs.

3. **Skill Books (`~606–1,130` raw points across FO3 + FNV):**
   - **Strongly support** shrinking bonuses (`+3` below skill `50`, `+2` at `50–74`, `+1` at `75+`, with *Comprehension* adding `+1` to temporary magazines or `+1` capped within the ceiling) **plus a hard per-skill book cap of `+20` permanent points per skill** (`260` max across all `13` skills). Without a per-skill cap, `Fallout3.esm`'s `305` placed books + respawning raider `LVLI` drops and `OldWorldBlues.esm`'s `13` `RCPE` recipes allow maxing skills with zero level-up investment.

## (b) Complete Fallout 4 S.P.E.C.I.A.L. Perk Chart Table (`70` Perks, `229` Base / `243` All-DLC Ranks)

### Classification & Threshold Rules
- **`SKILL` (`5` perks, `19` base / `19` all-DLC ranks):** Every rank is a pure tier gate or linear scalar (`COBJ` workbench tier, Stimpak/RadAway healing `%`) replaced `100%` by one of our `13` skills at **`25 / 50 / 75 / 100`**. Zero perk points spent.
- **`SPLIT` (`15` perks, `63` base / `64` all-DLC ranks -> `42` [`43`] folded + `21` kept):** Linear magnitude scaling (`+20%..+100%` weapon damage, lock/terminal tier access, stealth `%`, pickpocket `%`, vendor prices, chem/core efficiency, salvage yield) folds into the named skill at **`25 / 50 / 75 / 100`**, while specific ranks that attach a **discrete non-scalar mechanic** (e.g., unbreakable bobby pins, terminal lockout immunity, reverse-pickpocketing live grenades, VATS paralyzing palm, *Light Step*, *Silent Running*, Fusion Core grenade ejection) remain selectable `PERK`s gated by that skill.
- **`PERK` (`50` perks, `147` base / `160` all-DLC ranks):** Unique conditional, VATS, survival, mutation, companion, or settlement mechanics retained for the perk catalog (deduplicated against FO1/2/3/FNV perks in the next pass).
- **Top-Row S.P.E.C.I.A.L. Rescale (for kept `PERK`s and kept halves of `SPLIT` perks):** Rows `1..6` keep `Stat >= 1..6`; Rows `7, 8, 9, 10` rescale their attribute floor from `7, 8, 9, 10` to **`7, 8, 8, 9`** paired with a level/skill gate so `Pool = 40` characters with rare S.P.E.C.I.A.L. gains are never locked out of row-`9`/`10` archetypes.

### 4. Story Mode Complete-Reset Option vs Post-Completion Open-World Access

Under the owner's two-option continuity rule:
1. **Carried-Character Option (Story Carryover / Survival):** One persistent character keeps S.P.E.C.I.A.L., `13` skills, and deduplicated perks across every title on FO4's uncapped XP curve, governed by the stepped perk cadence / stepped `76–100` skill cost in Section `(a)` and world-tier threat scaling.
2. **Complete-Reset Option -> Free Access When Done:** Each title starts at Level `1` (`Pool = 40`, `1` Background, `0..2` Traits, `3` Tags, `FO4SF_PerkCadenceLevels = 1`), giving every standalone campaign clean Level `1 -> ~50–72` progression with zero cross-game power creep.
