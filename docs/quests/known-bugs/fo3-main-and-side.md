### `FO3M-01` — Birth Chargen Menu Close / Playpen Gate & Parent Escort Stall (`CG01` `0x014E83`)
- **Plain Functional Description:** From shipped known-issue lists and community unofficial-patch changelogs, `CG01SCRIPT` (`0x030769`, `Begin MenuMode` + `Begin GameMode`) can stall if the appearance/name menu closes out of expected order, if `CG01SpecialBookSCRIPT` (`0x02ECB9`) fails to register final SPECIAL allocation, or if `CG01DadLeaveRoom` (`0x02EAAF`) / `CG01PlaypenGateSCRIPT` (`0x02EA3C`) drops its door/gate open state before `CG01EndQuestTriggerSCRIPT` (`0x02ECBB`).
- **Occurs in Our Conversion?:** `Not applicable yet` (`CF-10` chargen/door pattern `Mitigated`) — `CG01` is not yet converted, but `FO4SF_NewGameQuest.psc` (`CF-10`) already implements bounded menu-close fallback timers and repeated `GetOpenState()` door retries (`OPEN-02`, `OPEN-03`).
- **Proposed Resolution:** `Fix directly (ours)` — Drive `CG01SpecialBookSCRIPT` through the `CF-6` `40`-point SPECIAL allocator callback, guard `CG01PlaypenGateSCRIPT` with `SetOpen(True)` state verification, and add a timeout fallback on `CG01DadLeaveRoom2` (`0x02ECC4`) so corridor progression cannot hang on NPC pathing.
- **PC Card Reproduction & Check:** Start a `Fallout 3` New Game (`CF-10` start-world selector), complete name/SPECIAL book allocation in `CG01`, exit the playpen and clinic corridor into `CG02`, and verify `fo4sf_fo3_cg01.0.log` logs `special_points_allocated=40`, `playpen_open=true`, and `stage 200`.
