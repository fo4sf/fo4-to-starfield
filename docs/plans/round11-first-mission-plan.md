## 2. `A4` — The Four Fallout 4 Guns (Items 1–7 Per Weapon)

**Common Binary Findings Across All 4 Guns:**
- **Mesh assembly (`Fallout4.esm` `OBTE` + `Fallout4 - Meshes.ba2`):** `10mm`, `LaserMusket`, and `PipeGun` use invisible dummy base `MODL`s (`10mmRecieverDummy.nif`, `LaserMusketDummyReciever.nif`, `DummyReciever.nif`) and attach visible parts via `ObjectTemplate[0]` (`Default = True`) `OMOD`s (`Minigun` uses `Minigun.nif` + `MinigunBarrel.nif`). Because weapon modding is out of scope (`round11-prompt.md` L68), an offline builder (`scripts/weapons/stage_r11_weapons.py`) converts each default `OMOD` NIF via `fo4sf.pipeline` and welds them along `BSConnectPoint::Parents` (`P-Barrel`, `P-Grip`, `P-Magazine`, `P-Scope`) into a rigid Starfield `WEAP` NIF aligned to the donor Starfield weapon's grip/muzzle transform.
- **Animations & Audio (`R15` Honesty):** Fallout 4 Havok 2014 `.hkx` weapon graphs cannot execute in Starfield `1.16.244.0` (`.af`/`.afx`/`.agx`), and **`0` converted weapon `.wem` sound files exist in any BA2 on disk today** (`Fallout4 - Sounds.ba2` holds raw `.wav`/`.xwm` files, whereas Starfield `WEAP` fire/reload hooks bind Wwise `SNDR` event IDs). Each gun therefore uses **100% Fallout 4 `FULL` name, converted FO4 1st/3rd-person model & textures, FO4 `AMMO` record/name/mesh, and FO4 damage/magazine/fire-rate numbers**, while borrowing a matching `Starfield.esm` animation keyword set (`AnimGrip*` + `Anim*`) and donor `SNDR` audio (**explicitly labeled as animation/sound stand-ins**).
